# PDF 한데모아

여러 PDF와 이미지(JPG, PNG) 파일을 원하는 순서로 골라 브라우저 안에서 바로 하나의 PDF로 합쳐주는 웹 도구입니다.

**바로 쓰기 (Claude 링크) → https://claude.ai/code/artifact/b28e0462-6f97-4d11-8161-7ad629387a73**

설치가 필요 없습니다. 위 링크를 열어 사용하면 됩니다. 다른 사람과 공유할 때도 이 링크만 전달하면 됩니다.

## 특징

- **설치 없음** — 링크를 열면 바로 사용할 수 있습니다.
- **PDF + 이미지 함께 합치기** — JPG·PNG 이미지를 추가하면 자동으로 한 페이지짜리 PDF로 변환되어 다른 PDF와 함께 합쳐집니다. 휴대폰 사진의 EXIF 회전 정보도 반영해 페이지가 옆으로 눕지 않습니다.
- **업로드 없음** — 파일은 서버로 전송되지 않고 [pdf-lib](https://pdf-lib.js.org/)를 이용해 브라우저 안에서만 처리됩니다.
- **순서 조정** — 추가한 파일을 드래그하거나 위/아래 버튼으로 순서를 바꿀 수 있습니다.
- **어디서나** — Windows/Mac/모바일 등 브라우저만 있으면 동작합니다.

## 사용 방법

1. 링크를 엽니다.
2. "파일 선택" 버튼을 누르거나 PDF·이미지 파일을 화면에 끌어다 놓아 합칠 파일들을 추가합니다.
3. 손잡이(⠿)를 드래그하거나 위/아래 화살표로 합칠 순서를 정합니다.
4. "PDF로 합치기" 버튼을 누르면 브라우저가 결과 파일을 바로 다운로드합니다.

## 구성

이 저장소는 같은 도구를 두 가지 버전으로 담고 있습니다. 화면과 병합 기능은 동일하고, 결과 파일을 저장하는 방식만 다릅니다.

- `pdf-merger.html` — Claude Artifact 전용 버전. 위 Claude 링크로 게시된 페이지의 원본이며, Claude의 파일 저장 기능(`window.claude` 저장 API)을 사용합니다. **Netlify 등 일반 웹 호스팅에는 이 파일을 쓰지 마세요** — Claude 화면 밖에서는 저장 기능이 동작하지 않습니다.
- `index.html` — **일반 웹 호스팅용(Netlify 등) 독립 실행 버전**. 완전한 HTML 문서이며, 브라우저 표준 다운로드 방식(Blob + `<a download>`)으로 파일을 저장합니다. Netlify에 배포할 때는 이 파일을 씁니다.

## Netlify에 배포하기

1. 이 저장소를 Netlify에 연결합니다.
2. 빌드 명령은 비워두고, **Publish directory는 저장소 루트(`.`)**로 둡니다. (`netlify.toml`에 이미 지정되어 있어 보통 자동으로 인식됩니다.)
3. 배포가 끝나면 Netlify가 준 주소(`https://<사이트이름>.netlify.app`)의 **루트 주소**로 접속합니다 — Netlify는 루트에서 `index.html`을 찾으므로, `pdf-merger.html`이 있던 이전 배포에서는 루트 주소가 404였습니다. `index.html`을 추가한 지금은 루트 주소로 바로 열립니다.

## 페이지 갱신하기

- Claude 링크: `pdf-merger.html`을 수정한 뒤 같은 URL로 다시 게시하면 링크는 그대로 유지된 채 내용만 갱신됩니다.
- Netlify: `index.html`을 수정해 이 저장소에 푸시하면 Netlify가 자동으로 다시 배포합니다.
