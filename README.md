# PDF 한데모아

여러 PDF 파일을 원하는 순서로 골라 브라우저 안에서 바로 하나로 합쳐주는 웹 도구입니다.

**바로 쓰기 → https://claude.ai/code/artifact/b28e0462-6f97-4d11-8161-7ad629387a73**

설치가 필요 없습니다. 위 링크를 열어 사용하면 됩니다. 다른 사람과 공유할 때도 이 링크만 전달하면 됩니다.

## 특징

- **설치 없음** — 링크를 열면 바로 사용할 수 있습니다.
- **업로드 없음** — PDF 파일은 서버로 전송되지 않고 [pdf-lib](https://pdf-lib.js.org/)를 이용해 브라우저 안에서만 처리됩니다.
- **순서 조정** — 추가한 파일을 드래그하거나 위/아래 버튼으로 순서를 바꿀 수 있습니다.
- **어디서나** — Windows/Mac/모바일 등 브라우저만 있으면 동작합니다.

## 사용 방법

1. 링크를 엽니다.
2. "파일 선택" 버튼을 누르거나 PDF 파일을 화면에 끌어다 놓아 합칠 파일들을 추가합니다.
3. 손잡이(⠿)를 드래그하거나 위/아래 화살표로 합칠 순서를 정합니다.
4. "PDF로 합치기" 버튼을 누르고, 저장 위치를 선택하면 완료됩니다.

## 구성

- `pdf-merger.html` — 도구의 전체 소스(마크업/스타일/스크립트를 담은 단일 파일)이며, 위 링크로 게시된 페이지의 원본입니다.

## 페이지 갱신하기

`pdf-merger.html`을 수정한 뒤 같은 URL로 다시 게시하면 링크는 그대로 유지된 채 내용만 갱신됩니다.
