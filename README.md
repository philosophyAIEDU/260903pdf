# PDF 한데모아

여러 PDF와 이미지(JPG, PNG) 파일을 원하는 순서로 골라 하나의 PDF로 합치거나, PDF 한 개를 원하는 방식으로 나눠주는 웹 도구입니다. 모두 브라우저 안에서 처리됩니다.

**바로 쓰기 (Claude 링크) → https://claude.ai/code/artifact/b28e0462-6f97-4d11-8161-7ad629387a73**

설치가 필요 없습니다. 위 링크를 열어 사용하면 됩니다. 다른 사람과 공유할 때도 이 링크만 전달하면 됩니다.

## 특징

- **설치 없음** — 링크를 열면 바로 사용할 수 있습니다.
- **PDF + 이미지 함께 합치기** — JPG·PNG 이미지를 추가하면 자동으로 한 페이지짜리 PDF로 변환되어 다른 PDF와 함께 합쳐집니다. 휴대폰 사진의 EXIF 회전 정보도 반영해 페이지가 옆으로 눕지 않습니다.
- **업로드 없음** — 파일은 서버로 전송되지 않고 [pdf-lib](https://pdf-lib.js.org/)를 이용해 브라우저 안에서만 처리됩니다.
- **순서 조정** — 추가한 파일을 드래그하거나 위/아래 버튼으로 순서를 바꿀 수 있습니다.
- **어디서나** — Windows/Mac/모바일 등 브라우저만 있으면 동작합니다.

## PDF 나누기

화면 위쪽의 **나누기** 탭에서 PDF 한 개를 올리고 방식을 고릅니다.

- **한 쪽씩** — 5쪽짜리면 5개 파일
- **N쪽씩** — 예: 2쪽씩이면 1-2, 3-4, 5
- **범위 직접 지정** — `1-2, 3, 4-5`처럼 쉼표로 구분한 범위마다 파일 하나
- **필요한 쪽만 뽑기** — `1-3, 5`처럼 적은 쪽들을 PDF 한 개로

결과가 여러 개면 ZIP 하나로 묶어 저장하고, 한 개면 PDF로 바로 저장합니다. (ZIP 생성에 [JSZip](https://stuk.github.io/jszip/) 사용)

## 합치기 사용 방법

1. 링크를 엽니다.
2. "파일 선택" 버튼을 누르거나 PDF·이미지 파일을 화면에 끌어다 놓아 합칠 파일들을 추가합니다.
3. 손잡이(⠿)를 드래그하거나 위/아래 화살표로 합칠 순서를 정합니다.
4. "PDF로 합치기" 버튼을 누르면 브라우저가 결과 파일을 바로 다운로드합니다.

## 구성

이 저장소는 같은 도구를 두 가지 버전으로 담고 있습니다. 화면과 병합 기능은 동일하고, 결과 파일을 저장하는 방식만 다릅니다.

- `pdf-merger.html` — Claude Artifact 전용 버전. 위 Claude 링크로 게시된 페이지의 원본이며, Claude의 파일 저장 기능(`window.claude` 저장 API)을 사용합니다. **Netlify 등 일반 웹 호스팅에는 이 파일을 쓰지 마세요** — Claude 화면 밖에서는 저장 기능이 동작하지 않습니다.
- `index.html` + `app.js` + `vendor/` — **일반 웹 호스팅용(Netlify 등) 독립 실행 버전**. 완전한 HTML 문서이며, 브라우저 표준 다운로드 방식(Blob + `<a download>`)으로 파일을 저장합니다. Netlify에 배포할 때는 이 파일들을 씁니다.

## 보안

`index.html`(Netlify/사내 공유용 버전)은 직원과 공유해도 문서가 새어나가지 않도록 구성했습니다.

- **외부 접속 0건** — pdf-lib·JSZip을 `vendor/`에 직접 포함해 CDN을 쓰지 않고, 구글 폰트도 제거했습니다(시스템 기본 글꼴 사용). CDN이 침해돼도 영향이 없습니다.
- **CSP 적용** — `script-src 'self'`, `connect-src 'none'`으로 페이지가 어디로도 데이터를 전송할 수 없게 막습니다. 인라인 스크립트를 `app.js`로 분리했습니다.
- **보안 헤더** — `netlify.toml`에서 CSP, `X-Frame-Options`, `nosniff`, `no-referrer`, HSTS, `Permissions-Policy`를 지정합니다. (`frame-ancestors`는 헤더로만 동작합니다.)
- 라이브러리: pdf-lib 1.17.1, JSZip 3.10.1 (npm 배포본 그대로, 라이선스 파일 동봉). 업데이트하려면 `vendor/` 파일을 교체하세요.
- 사내 한정이 필요하면 Netlify의 비밀번호 보호(유료) 또는 별도 접근 제한을 함께 쓰세요.
- `pdf-merger.html`(Claude 링크용)은 Claude 화면의 제약상 CDN 스크립트를 그대로 사용합니다. 민감한 문서는 `index.html` 버전을 쓰세요.

## Netlify에 배포하기

1. 이 저장소를 Netlify에 연결합니다.
2. 빌드 명령은 비워두고, **Publish directory는 저장소 루트(`.`)**로 둡니다. (`netlify.toml`에 이미 지정되어 있어 보통 자동으로 인식됩니다.)
3. 배포가 끝나면 Netlify가 준 주소(`https://<사이트이름>.netlify.app`)의 **루트 주소**로 접속합니다 — Netlify는 루트에서 `index.html`을 찾으므로, `pdf-merger.html`이 있던 이전 배포에서는 루트 주소가 404였습니다. `index.html`을 추가한 지금은 루트 주소로 바로 열립니다.

## 페이지 갱신하기

- Claude 링크: `pdf-merger.html`을 수정한 뒤 같은 URL로 다시 게시하면 링크는 그대로 유지된 채 내용만 갱신됩니다.
- Netlify: `index.html`/`app.js`를 수정해 이 저장소에 푸시하면 Netlify가 자동으로 다시 배포합니다.
